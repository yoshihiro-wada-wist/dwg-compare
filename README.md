# DWG Compare（重ね合わせ差分ビューア）Chrome拡張

2つのDWGをブラウザ内で読み込み、重ね合わせて差分を色分け表示します。
**削除（旧図Aのみ）= 赤 / 追加（新図Bのみ）= 青 / 共通 = グレー**。
解析・描画はすべてローカル（WASM）で完結し、ファイルは外部送信されません。

## インストール（未パッケージ拡張として読み込み）
1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ この `dwg-compare` フォルダを選択
4. ツールバーの拡張アイコンをクリック → 専用タブでビューアが開く

## 使い方
1. 「旧図(A)」「新図(B)」にそれぞれDWGを選択
2. 「比較」を押す
3. 赤=削除 / 青=追加 / グレー=共通 が重ねて表示される
   - チェックボックスで各クラスの表示ON/OFF
   - 「許容差」= 座標を丸める単位（図面単位）。同一とみなす厳密さ。既定 0.01
   - マウスドラッグでパン、ホイールでズーム、「全体表示」でフィット

## 差分判定の仕組み
各エンティティから幾何シグネチャ（種別＋丸めた座標）を作り、A/Bをマルチセットで突き合わせます。
両方にあれば「共通」、Aのみ「削除」、Bのみ「追加」。ハンドル（ID）は使いません
（保存で変わるため）。LINEの端点はA-B/B-Aを同一視するなど、向き違いも吸収しています。

## 現状の制限（要検証・改良ポイント）
- **ブロック(INSERT)は未展開**：挿入点に四角マーカー＋ブロック名のみ。挿入点・尺度・回転・名前が
  一致すれば「共通」。中身の差分は見ません。展開は今後の拡張で対応可能。
- **角度の単位**：ARC/楕円/回転は libredwg 内部表現（ラジアン想定）で実装。もし円弧の描画が
  おかしい場合、`viewer.js` の `arcPoints`/角度処理がまず疑うべき箇所です。
- **SPLINE** はフィット点／制御点を結ぶ折れ線近似（真のNURBS評価ではない）。
- **OCS/押し出し方向は未考慮**：通常の平面図（Z上向き）前提。Zミラー等は位置がずれる可能性。
- **寸法(DIMENSION)**：直線/並列寸法は補助線・寸法線・矢印・寸法値を描画。半径/直径/角度寸法は寸法値のみ（形状は簡易）。矢サイズ・字高は簡易固定（DIMSTYLE未参照）。
- **未対応エンティティ**：HATCH・MLINE・LEADER等は現状描画/差分対象外（件数は画面下に表示）。
- **libredwg自体の限界**：一部のDWG（独自オブジェクト、天正系など）は開けない/崩れることがあります。
  実際のIJCAD図面で必ず検証してください。
- WASM(embind)が実行時に eval を使うため、解析は **sandboxページ(iframe)** に隔離して実行しています
  （MV3の通常ページは `unsafe-eval` 不可のため）。解析はsandbox、差分・描画は通常ページで動きます。

## 構成
```
dwg-compare/
  manifest.json        … MV3。アイコンクリックでviewerタブを開く
  background.js        … action.onClicked → タブ生成
  viewer.html / .css   … UI
  viewer.js            … 差分・描画の本体（解析はsandboxへ委譲）
  sandbox.html / .js   … WASM解析を隔離実行（unsafe-eval許可ページ）
  vendor/
    dist/libredwg-web.js   … 高レベルAPI（ESM）
    wasm/libredwg-web.js   … Emscriptenローダ
    wasm/libredwg-web.wasm … LibreDWG本体（約6MB）
```

## 改良の入口（viewer.js）
- ブロック展開：`tables.BLOCK_RECORD` の各ブロックのエンティティを INSERT の
  挿入点・尺度・回転で変換して描画＋シグネチャに含める。
- 寸法/ハッチ対応：`entityToShapes` に分岐を追加。
- 「移動だけ検出」：共通でも座標が近いものをペアリングして矢印表示、等。
- レイヤ条件：シグネチャに `layer` を含めるトグルを追加。
